# yacht-cfd

An open-source CFD pipeline for yacht and performance-craft design, built
from scratch as a Maxsurf-adjacent alternative focused on parametric
geometry, validated 2D/3D analysis, and eventually a complete optimisation
loop.

The long-term goal is the closed loop yacht designers have wanted for
thirty years and no open-source project has shipped: parametric geometry
→ CFD → VPP → optimisation → repeat, producing theoretically optimal foils,
keels, rudders, and bulbs for a given set of design conditions.

## Status

Working pipeline as of V1:

- **Geometry generator** — NACA 4-digit sections with cosine-spaced points,
  Selig `.dat` and 3D extruded STL output, supporting tapered chord and
  spanwise twist for keel-style geometry.
- **Visual verifier** — side-by-side 2D section and 3D extrusion rendering
  via matplotlib.
- **XFOIL wrapper** — drives XFOIL across a user-specified alpha range at
  any Reynolds number, parses converged results from stdout, writes a
  `polar.csv` per design.
- **V&V harness** — runs the full pipeline across the canonical NACA
  reference sections (0012, 2412, 4412, 0015) and overlays results against
  NACA Report 824 wind-tunnel measurements.
- **Project-folder workflow** — every design lives in `projects/<name>/`
  with `parameters.json` as source of truth; analysis outputs accumulate
  in the same folder.

Validated against NACA Report 824 across four reference sections. See
the validation figure below.

## Validation

Four canonical NACA sections generated by `yacht-cfd`, run through XFOIL
at Re=3×10⁶, compared against wind-tunnel measurements from Abbott &
von Doenhoff (NACA Report 824, 1945). Lift coefficient agrees within
experimental scatter across the operating range and into pre-stall. Drag
coefficient shows the systematic XFOIL underprediction typical of
integral boundary-layer methods — consistent across all four sections,
indicating the pipeline behaviour is physically correct rather than
geometrically biased.

## Usage

Requires Python 3, matplotlib, and XFOIL in `PATH`. On Gentoo:

```bash
sudo emerge dev-python/matplotlib sci-physics/xfoil
```

Create a new design:

```bash
python scripts/new_design.py main_keel \
    --naca 0012 --chord 1.0 --tip-chord 0.6 --span 1.5 --twist -3
```

Run XFOIL on it:

```bash
python scripts/xfoil_polar.py main_keel --re 3e6 --alpha -10 18 0.5
```

Plot the polar with reference data overlay:

```bash
python scripts/plot_polar.py main_keel
```

Run the full V&V harness across all four reference sections:

```bash
python scripts/validate.py
```

## Roadmap

Near-term (V1.x):
- AVL integration for 3D loading, induced drag, and spanwise centre of
  effort via strip theory coupled with XFOIL profile drag.
- Beam-theory structural model with EI/GJ as user inputs; static
  aeroelastic loop for foil deflection under load.
- Cache layer keyed on input parameters so future runs of the same
  evaluation are instant.

Mid-term (V2):
- OpenFOAM 2D and 3D RANS integration as the high-fidelity tier.
- Bulb generator (torpedo, T-bulb with winglets).
- Rudder class hierarchy (balanced spade, skeg-hung, twin, T-foil).
- Class-rule constraint layer for design-space filtering.
- Pareto-front optimisation across multi-objective design problems
  (upwind VMG, downwind VMG, reaching, course time).

Long-term:
- Python-VPP integration for whole-boat performance evaluation.
- Towing-tank validation interface.
- Surrogate models trained on the accumulated cache.
